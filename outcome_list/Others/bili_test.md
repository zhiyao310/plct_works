# B站视频去水印及二次剪辑操作文档

## 一、 环境准备与软件下载

| 软件名称                 | 用途                                | 官方/安全下载链接                                            |
| :----------------------- | :---------------------------------- | :----------------------------------------------------------- |
| **BiliTools**            | B站视频批量下载（支持多UP主、合集） | 下载最新版 `BiliTools-x.x.x-windows-x64.zip`                 |
| **ImageJ**               | 科学图像分析，精确定位水印像素坐标  | [美国国立卫生研究院(NIH)官方链接](https://imagej.net/ij/download.html) （下载 `ijxxx.zip` 免安装版） |
| **FFmpeg**               | 工业级视频处理，去水印/转码/合并    | [FFmpeg官网](https://ffmpeg.org/download.html) （Windows选 `gyan.dev` 的 `essentials_build` 或 `full_build`） |
| **剪映**<br>*(可选替代)* | 图形化加片头片尾/变速/换BGM         | 官方APP                                                      |

## 二、 第一步：使用 BiliTools 下载原视频

1. 解压并运行 BiliTools（通常为双击 `.exe` 或通过命令行启动）。

2. 在界面中输入账号主页链接或具体视频的 BV 号。

3. 选择下载画质（建议选择 **1080P 高码率**，避免二次压缩画质损失严重）。

4. 设置保存路径，等待下载完成。

5. *注意：下载后的文件名可能较长，建议先重命名为简单的英文名（如 `0514test.mp4`），方便后续命令行操作。*

## 三、 第二步：使用 ImageJ 精确获取水印坐标

由于同一账号的视频片头/片尾水印位置通常是固定的，**此步骤只需做一次，后续可复用坐标数据**。

1. **打开图片**：将下载好的视频随便截一张图（或者用播放器暂停截图），保存为 PNG 或 JPG 格式。打开 ImageJ，将图片拖入 ImageJ 窗口。
2. **选择工具**：在工具栏选择 **矩形选框工具**（Rectangular selection，图标为小方框）。
3. **框选水印**：用鼠标在水印区域画一个矩形，**尽量贴近水印边缘，不要留太多空白，也不要切掉水印**。
4. **读取坐标**：画完选区后，查看 ImageJ 主窗口菜单栏下方的状态栏，会显示类似 `x=6, y=10, w=442, h=94` 的数据。
   - `x`：选区左上角的横坐标（像素）
   - `y`：选区左上角的纵坐标（像素）
   - `w`：选区的宽度（像素）
   - `h`：选区的高度（像素）
5. **记录坐标**：将这四个数值记录下来，这就是 FFmpeg `delogo` 滤镜所需的核心参数。
   ![image-20260515143633766](https://github.com/zhiyao310/plct_works/blob/main/outcome_list/Others/images/image-20260515143633766.png)

## 四、 第三步：使用 FFmpeg 去除水印

1. **准备环境**：将 FFmpeg 解压，并确保 `ffmpeg.exe` 所在目录已添加到系统环境变量，或者直接在 `ffmpeg.exe` 所在文件夹的地址栏输入 `cmd` 回车打开命令行。
2. **执行去水印命令**：
   输入以下命令（请根据实际路径和 ImageJ 测出的坐标替换参数，`-i 0514test.mp4`：输入的原视频文件）：

```bash
ffmpeg -i 0514test.mp4 -vf delogo=x=6:y=16:w=436:h=88 0514test_1.mp4
```

## 五、 第四步：视频深度编辑

B站的查重不仅是查水印，更核心的是“画面抽帧比对”和“音频波形比对”。

1. 将 `0514test_1.mp4` 导入bilibili直接编辑，或者使用剪映。
2. **加片头片尾**：拖入自己制作的片头和片尾素材。
3. **中间变速**：选中主视频，选择“变速”，建议 **1.2x 或 1.3x**。
4. **加入背景音**：添加新的 BGM，改变整体音频指纹。
5. 上传/导出视频。
   ![image-20260515144548961](https://github.com/zhiyao310/plct_works/blob/main/outcome_list/Others/images/image-20260515144548961.png)

上述操作可保证视频的成功发布，但如果只做了上述步骤，对于大批量搬运视频后容易面临：**审核秒过，但限流。**

**可在剪辑阶段加入以下“破坏视频指纹”的操作**：

1. **画面裁剪与缩放**：不要保持原视频尺寸。如果是 16:9 (1920x1080)，稍微裁剪一点上下边缘，缩放成 18:9 或加上边框重新填充为 16:9。这会直接改变所有画面的像素坐标分布，**是防画面查重最有效的方法**。
2. **全局微调滤镜**：增加亮度 +2，对比度 +3，饱和度 -2。肉眼看似没区别，但像素 RGB 值已全变，可破坏基于感知哈希的查重算法。
3. **音频重采样**：在导出时，如果原视频是 48000Hz，导出时选择 44100Hz；或者选择稍微不同的比特率。
